Spearfisher starter (kit K00, Session 1)

Open this folder in Godot 4.6. Then copy your own SpearFishing Assets Pack in:
its "Sprites" folder and "Licence.txt" go into assets/ (see assets/Sprites/PUT_YOUR_PACK_HERE.txt).

pictures the studio drew (assets/made_here: a small spear, a boat, a pixel font). No scripts yet.
