# Spearfisher

My cozy 2D spearfishing game, built in Godot 4.6.

## Before you open it
This repo has **no art pack in it** (the artist's licence says it can't be shared).
After you clone it:
1. Download the SpearFishing Assets Pack: https://nszym.itch.io/spearfishing-assets-pack
2. Copy its `Sprites` folder and `Licence.txt` into `assets/`, so you have `assets/Sprites/Diver-32x32/...`
3. Open `project.godot` in Godot 4.6.

## End of every session
Save in Godot, then commit and push (that's your backup).
